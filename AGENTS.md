# AGENTS.md

## Project
NV TEAM Smart Grid Platform - AI-powered smart grid and energy management competition demo.

## Rules
- Do not remove existing working features.
- Do not delete existing API routes.
- Do not commit `.env`, secrets, API keys, local DB files, `.next`, `node_modules`, or `__pycache__`.
- Use demo data when backend or real data is unavailable.
- Keep all AI actions as decision-support only.
- Human operator remains in control.

## Frontend
- Use Next.js, TypeScript, React, and TailwindCSS.
- Keep UI responsive for desktop and laptop.
- Prefer reusable components under `frontend/src/components/`.
- Prefer utility logic under `frontend/src/lib/`.

## Backend
- Use FastAPI.
- Keep existing route structure.
- Add demo endpoints only when useful and safe.

## Verification
- Run frontend lint/build if available.
- Start backend or run tests if available.
- Fix TypeScript and Python errors before final summary.
